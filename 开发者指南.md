# LiteNote 开发者指南

## 一、快速开始

### 1.1 环境要求

```
Node.js: >= 18.0.0
npm: >= 9.0.0
或
yarn: >= 3.0.0
或
pnpm: >= 7.0.0

操作系统: Windows / macOS / Linux
编辑器推荐: VS Code + 相关插件
```

### 1.2 开发环境配置

#### 安装依赖

```bash
# 克隆仓库
git clone https://github.com/litenote/litenote.git
cd litenote

# 安装依赖
pnpm install

# 或使用 npm
npm install

# 或使用 yarn
yarn install
```

#### 配置环境变量

```bash
# 复制环境模板
cp .env.example .env.local

# 编辑 .env.local 文件
# 主要变量:
VITE_API_BASE_URL=http://localhost:3000/api/v1
VITE_STORAGE_PATH=./notes
VITE_DEV_MODE=true
```

#### 运行开发服务器

```bash
# 启动前端开发服务器
pnpm dev

# 或启动完整开发环境（包括后端）
pnpm dev:full

# 访问 http://localhost:5173
```

### 3.2 状态管理 (Pinia)

```typescript
// packages/stores/notes.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { Note } from '@/types/models'

export const useNoteStore = defineStore('notes', () => {
  // State
  const notes = ref<Note[]>([])
  const selectedNoteId = ref<string | null>(null)
  const loading = ref(false)
  const error = ref<string | null>(null)

  // Computed
  const selectedNote = computed(() => {
    return notes.value.find(n => n.id === selectedNoteId.value)
  })

  // Methods
  const fetchNotes = async () => {
    loading.value = true
    try {
      // 调用 API
      const response = await api.notes.list()
      notes.value = response.data
      error.value = null
    } catch (err) {
      error.value = err.message
    } finally {
      loading.value = false
    }
  }

  const selectNote = (id: string) => {
    selectedNoteId.value = id
  }

  return {
    notes,
    selectedNote,
    selectedNoteId,
    loading,
    error,
    fetchNotes,
    selectNote,
  }
})
```

### 3.3 API 调用

```typescript
// apps/web/src/api/http.ts
import axios from 'axios'

const instance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 30000,
})

// 请求拦截器
instance.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截器
instance.interceptors.response.use(
  (response) => response.data,
  async (error) => {
    if (error.response?.status === 401) {
      // 处理 Token 过期
      // ...
    }
    return Promise.reject(error)
  }
)

export default instance

// apps/web/src/api/notes.ts
import http from './http'
import type { Note, CreateNoteRequest } from '@/types/models'

export const notesApi = {
  // 获取笔记列表
  list: (params?: { page?: number; limit?: number }) =>
    http.get<Note[]>('/notes', { params }),

  // 获取单个笔记
  get: (id: string) => http.get<Note>(`/notes/${id}`),

  // 创建笔记
  create: (data: CreateNoteRequest) =>
    http.post<Note>('/notes', data),

  // 更新笔记
  update: (id: string, data: Partial<Note>) =>
    http.patch<Note>(`/notes/${id}`, data),

  // 删除笔记
  delete: (id: string) => http.delete(`/notes/${id}`),
}
```

## 四、开发工作流

### 4.1 分支策略（Git Flow）

```
main                       # 正式版本分支
├─ release/*              # 发布分支（如 release/v1.0.0）
└─ develop                # 开发分支
   ├─ feature/*           # 功能分支（如 feature/dark-mode）
   ├─ bugfix/*            # bug 修复分支（如 bugfix/login-issue）
   └─ refactor/*          # 重构分支（如 refactor/api-client）

工作流:
1. 从 develop 创建功能分支: git checkout -b feature/my-feature
2. 提交 PR 到 develop
3. 代码审查通过后合并
4. 定期从 develop 创建 release 分支
5. 合并 release 到 main，打 tag
```

### 4.2 提交规范（Conventional Commits）

```
格式:
<type>(<scope>): <subject>
<BLANK LINE>
<body>
<BLANK LINE>
<footer>

类型:
├─ feat: 新功能
├─ fix: 修复 bug
├─ docs: 文档更新
├─ style: 代码风格调整（不影响功能）
├─ refactor: 代码重构
├─ perf: 性能优化
├─ test: 添加或修改测试
├─ chore: 构建或依赖更新
└─ ci: CI/CD 配置更新

示例:
feat(editor): add component picker

Implement a new component picker for adding content blocks to notes.
Users can now easily insert predefined or custom components.

Closes #123
Related to #456
```

## 六、编辑器开发

### 6.1 编辑器核心架构

```typescript
// apps/web/src/components/editor/Editor.vue
<template>
  <div class="editor">
    <EditorToolbar @insert-block="insertBlock" />
    <div class="editor-content">
      <div
        v-for="(block, index) in blocks"
        :key="block.id"
        class="block"
        @click="selectBlock(index)"
      >
        <component
          :is="`LiteNoteComponent${capitalize(block.type)}`"
          :model-value="block"
          @update="updateBlock(index, $event)"
          @delete="deleteBlock(index)"
        />
      </div>
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { v4 as uuidv4 } from 'uuid'
import type { Block } from '@/types/models'

interface Props {
  modelValue: string
}

const props = defineProps<Props>()
const emit = defineEmits<{ 'update:modelValue': [string] }>()

const blocks = ref<Block[]>([])
const selectedBlockId = ref<string | null>(null)

const insertBlock = (type: string) => {
  const newBlock: Block = {
    id: uuidv4(),
    type,
    properties: {},
  }
  blocks.value.push(newBlock)
}

const updateBlock = (index: number, data: Partial<Block>) => {
  blocks.value[index] = { ...blocks.value[index], ...data }
}

const deleteBlock = (index: number) => {
  blocks.value.splice(index, 1)
}

const selectBlock = (index: number) => {
  selectedBlockId.value = blocks.value[index].id
}
</script>

  padding: 8px;
  border-radius: 4px;
  transition: background 200ms ease;
}

  background: #f5f5f5;
}
</style>
```

### 9.2 性能监控

```typescript
// apps/web/src/utils/performance.ts
export const measurePerformance = (name: string) => {
  const start = performance.now()
  return () => {
    const end = performance.now()
    logger.log(`${name} took ${(end - start).toFixed(2)}ms`)
  }
}

// 使用示例
const stopMeasure = measurePerformance('fetchNotes')
await fetchNotes()
stopMeasure()
```
